# CHAPTER 4: DATASET COLLECTION\n\n## 4.1 Best Public EEG Alzheimer's Datasets\n\n### 4.1.1 ADNI (Alzheimer's Disease Neuroimaging Initiative)\n\n**Overview:**\n- **URL**: http://adni.loni.usc.edu/\n- **Founded**: 2003\n- **Subjects**: 1,500+ participants\n- **Countries**: USA and Canada\n- **Data Types**: MRI, PET, CSF, EEG, cognitive assessments\n- **EEG Recordings**: 64-channel Neuroscan system\n\n**Registration Process:**\n\n1. **Create Account**\n   - Go to adni.loni.usc.edu\n   - Click \"Register/Login\"\n   - Fill registration form\n   - Verify email\n\n2. **Complete Application**\n   - Provide researcher information\n   - Research institution details\n   - Project description\n   - Data usage agreement\n\n3. **Approval**\n   - Wait for IRB/data use approval (1-2 weeks)\n   - Receive download instructions\n   - Access data portal\n\n**Data Available:**\n- Baseline EEG recordings\n- Follow-up recordings (years 1, 2, 3)\n- Resting state (eyes open/closed)\n- Cognitive test results\n- Neuroimaging data\n\n**Participant Categories:**\n- Normal cognition (NC)\n- Mild Cognitive Impairment (MCI)\n- Alzheimer's Disease (AD)\n- EMCI/LMCI (Early/Late MCI)\n\n**Sampling:** 100-250 Hz\n**Channels:** 64 electrodes\n**Duration:** 5-10 minutes per session\n**File Format:** EDF, EEGLAB .set\n\n### 4.1.2 OASIS (Open Access Series of Imaging Studies)\n\n**Overview:**\n- **URL**: https://www.oasis-brains.org/\n- **Founded**: 2007\n- **Subjects**: 1,000+ participants\n- **Primary Data**: MRI, PET\n- **EEG Available**: Selected subset\n\n**Registration:**\n1. Visit oasis-brains.org\n2. Click \"Get Data\"\n3. Create free account\n4. Accept license terms\n5. Immediate download access\n\n**Advantages:**\n- **Open Access**: No approval needed\n- **Free**: Completely free to download\n- **Quick**: Immediate access\n- **Multiple Modalities**: MRI, PET, demographics\n\n**Datasets:**\n- OASIS-1: Cross-sectional (416 subjects)\n- OASIS-2: Longitudinal (150 subjects, 30 years)\n- OASIS-3: Multimodal (1,098 subjects)\n\n**EEG Availability:** Limited subset\n**Format:** Various (NIfTI for MRI)\n\n### 4.1.3 PhysioNet EEG Databases\n\n**Overview:**\n- **URL**: https://physionet.org/\n- **Database**: Multiple public health datasets\n- **Immediate Access**: No registration for most\n\n**Key EEG Databases:**\n\n**A. Sleep EEG**\n- https://physionet.org/content/sleep-edfx/1.0.0/\n- 197 subjects\n- Sleep stages\n- Aging effects\n\n**B. Temple University Hospital EEG**\n- Seizure detection dataset\n- 24 patients\n- Normal and abnormal EEG\n\n**C. Aging and Dementia**\n- Limited but relevant\n- Longitudinal recordings\n- Multiple visits\n\n**Download Method:**\n```bash\n# Example: Download PhysioNet data\nwget -r -N -c -np https://physionet.org/files/dataset-name/\n```\n\n### 4.1.4 Kaggle EEG Alzheimer's Datasets\n\n**Overview:**\n- **URL**: https://www.kaggle.com/\n- **Search**: \"EEG Alzheimer's\"\n- **Format**: Usually preprocessed CSV\n\n**Notable Datasets:**\n\n1. **\"EEG Data for Alzheimer's\"**\n   - 88 subjects\n   - 3 classes: AD, MCI, Normal\n   - 64 features extracted\n   - CSV format (easy to use)\n   - **Link**: kaggle.com/datasets\n\n2. **\"EEG Alzheimer Classification\"**\n   - 150 subjects\n   - Binary classification (AD vs Normal)\n   - 14 EEG channels\n   - Time-series data\n\n**Advantages:**\n- Pre-processed data\n- CSV format ready for analysis\n- No complex registration\n- Featured in competitions\n\n**Disadvantages:**\n- Limited metadata\n- Already feature-extracted\n- No raw signals\n- May have privacy concerns\n\n### 4.1.5 OpenNeuro\n\n**Overview:**\n- **URL**: https://openneuro.org/\n- **Repository**: Open EEG/fMRI datasets\n- **Access**: Free, immediate download\n\n**Features:**\n- BIDS format (standardized)\n- Curated quality\n- Published in research\n- Versioning support\n\n**How to Access:**\n1. Visit openneuro.org\n2. Search \"EEG Alzheimer's\" or \"dementia\"\n3. Click dataset\n4. Download button → OSF storage or DataLad\n\n**Search Tips:**\n- Use keywords: Alzheimer, dementia, cognitive, aging\n- Filter by modality: EEG\n- Filter by tasks: Resting state, task\n\n---\n\n## 4.2 Dataset Download Procedures\n\n### 4.2.1 ADNI Download\n\n**Step-by-Step:**\n\n1. **Create ADNI Account**\n   ```\n   Website: http://adni.loni.usc.edu/\n   Click: \"New User Registration\"\n   Fill: Name, email, institution\n   ```\n\n2. **Complete Data Use Agreement**\n   ```\n   - Accept terms and conditions\n   - Agree to publication policy\n   - Provide research purpose\n   - Submit for approval\n   ```\n\n3. **Access Data Portal**\n   ```\n   - Wait for approval email (1-2 weeks)\n   - Click approval link\n   - Download files or use LONI IDA\n   ```\n\n4. **Download Data**\n   ```\n   Option A: Web interface\n   - Browse studies\n   - Select subjects\n   - Download EEG files\n   \n   Option B: LONI IDA Tool\n   - Download metadata CSV\n   - Batch download scripts\n   - Automated file organization\n   ```\n\n**Example ADNI EEG Files:**\n```\nADNI_001_S_0001_ses_01_eeg.edf\nADNI_001_S_0002_ses_01_eeg.edf\nADNI_002_S_0003_ses_01_eeg.edf\n...\n```\n\n### 4.2.2 OASIS Download (Easiest!)\n\n**Quick Steps:**\n```\n1. ├── eeg/\n│   │   │   │   └── subject_001_ses01.edf\n│   │   │   └── demographics.csv\n│   │   ├── ses_02/\n│   │   └── ses_03/\n│   ├── 002/\n│   └── 003/\n├── Metadata/\n│   ├── subjects.csv\n│   ├── diagnosis.csv\n│   └── cognitive_scores.csv\n└── Documentation/\n    ├── README.md\n    └── data_dictionary.txt\n```\n\n### 4.3.2 File Formats\n\n**EDF Format (EuroData Format)**\n```\n.edf files contain:\n- Raw EEG signals\n- Electrode information\n- Sampling rate\n- Recording parameters\n- Subject demographics\n```\n\n**CSV Format**\n```\nTime, Channel_Fp1, Channel_Fp2, ..., Channel_Oz\n0.000, 12.5, 11.2, ..., 10.8\n0.002, 13.1, 12.0, ..., 11.2\n0.004, 12.8, 11.8, ..., 10.9\n...\n```\n\n**Label Structure:**\n```\nsubject_id, diagnosis, age, gender, mmse_score\n001, NC, 75, M, 29\n002, MCI, 78, F, 26\n003, AD, 82, M, 18\n...\n```\n\n---\n\n## 4.4 Labels and Classes\n\n### 4.4.1 Standard Classification\n\n| Class | Label | Criteria |\n|-------|-------|----------|\n| Additional Metadata\n\n```\nAge: 55-95 years\nGender: M/F\nMMSE Score: 0-30\nCDR (Clinical Dementia Rating): 0, 0.5, 1, 2, 3\nAPOE4 Status: Positive/Negative\nEducation: Years\n```\n\n---\n\n## 4.5
