# CHAPTER 5: DATA UNDERSTANDING\n\n## 5.1 EEG File Formats\n\n### 5.1.1 EDF (European Data Format)\n\n**Overview:**\n- **Full Name**: European Data Format\n- **Extension**: .edf, .eeg\n- **Standard**: ISO 14271\n- **Binary Format**: Yes\n\n**File Structure:**\n```\nHeader (256 bytes)\n├── Version: 0\n├── Patient Info: Name, DOB, Gender\n├── Recording Info: Startdate, Starttime\n├── Number of records: N\n├── Duration per record: 1 second\n├── Number of signals: 64\n└── Signal Headers (256 bytes each per signal)\n    ├── Label: Fp1, Fp2, ..., Oz\n    ├── Transducer: Electrode location\n    ├── Physical dimension: μV\n    ├── Physical min/max: -10000 to 10000\n    ├── Digital min/max: -32768 to 32767\n    ├── Prefiltering: Frequency range\n    └── Number of samples per record\n\nData Records\n├── Signal 1 samples (1 second)\n├── Signal 2 samples\n└── ... Signal N samples\n```\n\n**Advantages:**\n- International standard\n- Metadata included\n- Widely supported\n- Free and open\n\n**Disadvantages:**\n- Less compression\n- Larger file size\n- Complex parsing required\n\n**Reading EDF in Python:**\n```python\nimport mne\n\n# Read EDF file\nraw = mne.io.read_raw_edf('subject_001.edf')\n\n# Extract information\nprint(raw.info)  # Channel info, sampling rate\nprint(raw.times)  # Time points\nprint(raw.get_data())  # Signal data (channels × samples)\n```\n\n### 5.1.2 CSV Format\n\n**Overview:**\n- **Format**: Comma-separated values\n-
